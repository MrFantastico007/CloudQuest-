# Gemini Enterprise: Walkthrough and Simulation Assessment Answers

This README contains the questions, correct answers, and explanations for the **Gemini Enterprise: Walkthrough and Simulation Assessment** lesson.

## Assessment Questions and Answers

### 1. Which synchronization frequency should you choose for weekly sales reports that update on a schedule?

**Answer:** Periodic

**Explanation:** Weekly sales reports update on a schedule, so a periodic sync matches that cadence. Streaming is intended for continuous, real-time data, while a one-time sync will not pick up new reports automatically.

### 2. What should you ask the AI assistant to do when you want to understand a customer sentiment pie chart?

**Answer:** Ask the AI assistant to “Summarize the customer sentiment pie chart.”

**Explanation:** Gemini Enterprise can interpret supported images when they are available to the assistant. A direct summarization prompt asks it to explain the chart's key information.

### 3. How will Gemini Notebook generate an answer when it is grounded in uploaded documents?

**Answer:** It will generate an answer based only on the content of the uploaded documents.

**Explanation:** Gemini Notebook grounds its response in the sources provided to the notebook. It does not automatically use unrelated web content or other data sources unless they are available as sources.

### 4. Which data type should you choose for structured e-commerce information such as product IDs, prices, and stock levels?

**Answer:** Tabular/E-commerce

**Explanation:** Structured fields such as product IDs, prices, and inventory levels are suited to tabular or e-commerce data ingestion, allowing users to work with attributes and filter relevant information.

### 5. Which agent should you use to autonomously research multiple external web sources and compile a comprehensive report?

**Answer:** Deep Research agent

**Explanation:** The Deep Research agent is designed to investigate information across multiple sources and synthesize its findings into a detailed report.

### 6. What should you configure first during the initial identity setup for Gemini Enterprise?

**Answer:** Choose an identity provider

**Explanation:** Selecting an identity provider establishes the identity and authentication foundation for users accessing Gemini Enterprise and connected resources.

### 7. How does Gemini Enterprise handle access to documents protected by existing permissions?

**Answer:** Users can only access documents already shared with them via existing permissions.

**Explanation:** Gemini Enterprise respects the access controls and permissions of connected data sources. It should not grant users access to documents they are not authorized to view.

### 8. Which Gemini Enterprise feature lets you upload a specific set of sources and generate overviews grounded in those files?

**Answer:** Gemini Notebook

**Explanation:** Gemini Notebook lets users work with a defined collection of sources and generate summaries or overviews grounded in those materials, including supported audio or video overview features where available.
