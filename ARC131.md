# Google Cloud Speech-to-Text Lab Automation

A copy-paste-ready Bash automation script for Google Cloud Skills Boost / Qwiklabs. It processes English and Spanish audio using the Google Cloud Speech-to-Text API and uploads request and response JSON files to Cloud Storage.

## Features

- Automatically detects the active Google Cloud project.
- Creates the destination Cloud Storage bucket if it does not exist.
- Enables the Speech-to-Text and Cloud Storage APIs.
- Processes English and Spanish audio files.
- Generates request and response JSON files.
- Automatically retries a request with `audioChannelCount = 1` if the API reports a channel-count mismatch.
- Uploads all request and response files to Cloud Storage.
- Displays the resulting files after successful execution.

## Requirements

- An active Google Cloud Skills Boost / Qwiklabs lab.
- Google Cloud Shell with `gcloud`, `curl`, and `jq` available.
- A valid Google Cloud Speech-to-Text API key.
- Permission to use the Speech-to-Text API and create or access Cloud Storage buckets.

## Step 1: Open Google Cloud Shell

Open Cloud Shell from your active lab.

Check the active Google Cloud project:

```bash
gcloud config get-value project
```

Make sure this is the project associated with your current lab.

## Step 2: Create the Bash script

Run the following command in Cloud Shell:

```bash
nano run_lab.sh
```

Copy the entire script from the **Complete Script** section below and paste it into Nano.

Before saving, replace the API key placeholder with your actual Google Cloud API key.

Save and exit Nano:

1. Press `Ctrl+O`.
2. Press `Enter`.
3. Press `Ctrl+X`.

## Step 3: Run the automation

Execute these commands:

```bash
chmod +x run_lab.sh
./run_lab.sh
```

The script will enable the required APIs, check the destination bucket, submit the transcription requests, and upload the resulting JSON files.

## Complete Script: `run_lab.sh`

Copy the complete code below into `run_lab.sh`.

```bash
#!/usr/bin/env bash
set -euo pipefail

# ==============================================================================
# 1. USER-EDITABLE VARIABLES
# ==============================================================================

# Paste your actual Google Cloud API key here.
USER_API_KEY="REPLACE_ME_WITH_YOUR_ACTUAL_API_KEY"

# Task 2: English Transcription
EN_REQ_FILE="speech_request_en.json"
EN_RES_FILE="speech_response_en.json"
EN_AUDIO_URI="gs://spls/arc131/question_en.wav"
EN_LANG="en-US"
EN_CHANNELS=2

# Task 3: Spanish Transcription
SP_REQ_FILE="request_sp.json"
SP_RES_FILE="response_speech_sp.json"
SP_AUDIO_URI="gs://spls/arc131/multi_es.flac"
SP_LANG="es-ES"
SP_CHANNELS=2

# If the API reports that the requested audio channel count does not match
# the audio file header, the script retries the request using channel count 1.
#
# The English and Spanish channel counts are handled independently.
# Only the request that returns the mismatch error is retried.

# ==============================================================================
# 2. DYNAMIC CONFIGURATION
# ==============================================================================

echo "Fetching active Project ID..."

export GOOGLE_CLOUD_PROJECT="$(gcloud config get-value project 2>/dev/null)"

if [[ -z "${GOOGLE_CLOUD_PROJECT}" ||
      "${GOOGLE_CLOUD_PROJECT}" == "(unset)" ]]; then
    echo "ERROR: No active Google Cloud project is configured."
    exit 1
fi

export BUCKET_NAME="${GOOGLE_CLOUD_PROJECT}-speech"

echo "Project ID: ${GOOGLE_CLOUD_PROJECT}"
echo "Target Bucket: gs://${BUCKET_NAME}"

if [[ "${USER_API_KEY}" == "REPLACE_ME_WITH_YOUR_ACTUAL_API_KEY" ||
      -z "${USER_API_KEY}" ]]; then
    echo "ERROR: Replace USER_API_KEY with your actual Google Cloud API key."
    exit 1
fi

export API_KEY="${USER_API_KEY}"

# ==============================================================================
# 3. ENABLE REQUIRED APIS
# ==============================================================================

echo "Enabling required APIs..."

gcloud services enable \
    speech.googleapis.com \
    storage.googleapis.com \
    --project="${GOOGLE_CLOUD_PROJECT}"

# ==============================================================================
# 4. PREPARE CLOUD STORAGE BUCKET
# ==============================================================================

echo "Checking Cloud Storage bucket..."

if ! gcloud storage ls "gs://${BUCKET_NAME}" >/dev/null 2>&1; then
    echo "Creating bucket gs://${BUCKET_NAME}..."

    gcloud storage buckets create "gs://${BUCKET_NAME}" \
        --project="${GOOGLE_CLOUD_PROJECT}" \
        --location=US
else
    echo "Bucket already exists. Skipping creation."
fi

# ==============================================================================
# 5. REUSABLE SPEECH-TO-TEXT API FUNCTION
# ==============================================================================

process_audio() {
    local req_file="$1"
    local res_file="$2"
    local audio_uri="$3"
    local lang="$4"
    local channels="$5"
    local error_message=""

    echo
    echo "==========================================================="
    echo "Processing transcription for: ${lang}"
    echo "Audio URI: ${audio_uri}"
    echo "Initial audio channel count: ${channels}"
    echo "==========================================================="

    # Generate the Speech-to-Text request JSON.
    write_request() {
        local channel_count="$1"

        cat > "${req_file}" <<EOF
{
  "config": {
    "languageCode": "${lang}",
    "audioChannelCount": ${channel_count}
  },
  "audio": {
    "uri": "${audio_uri}"
  }
}
EOF
    }

    # Call the Speech-to-Text API.
    call_speech_api() {
        curl -sS -X POST \
            -H "Content-Type: application/json" \
            --data-binary @"${req_file}" \
            "https://speech.googleapis.com/v1/speech:recognize?key=${API_KEY}" \
            -o "${res_file}"
    }

    echo "Generating request file: ${req_file}..."

    write_request "${channels}"

    echo "Calling Speech-to-Text API..."

    if ! call_speech_api; then
        echo "ERROR: Could not connect to the Speech-to-Text API."
        exit 1
    fi

    error_message="$(
        jq -r '.error.message // empty' "${res_file}" 2>/dev/null || true
    )"

    # --------------------------------------------------------------------------
    # AUTOMATIC FIX: AUDIO CHANNEL COUNT MISMATCH
    # --------------------------------------------------------------------------

    if [[ -n "${error_message}" &&
          "${error_message}" == *audio_channel_count* &&
          "${error_message}" == *"FLAC header"* &&
          "${channels}" != "1" ]]; then

        echo
        echo "Audio channel count mismatch detected for ${lang}."
        echo "API error: ${error_message}"
        echo "Retrying this request with audioChannelCount = 1..."

        channels=1

        # Regenerate the request with the corrected channel count.
        write_request "${channels}"

        echo "Calling Speech-to-Text API again..."

        if ! call_speech_api; then
            echo "ERROR: API request failed during the retry."
            exit 1
        fi

        error_message="$(
            jq -r '.error.message // empty' "${res_file}" 2>/dev/null || true
        )"
    fi

    # --------------------------------------------------------------------------
    # CHECK FOR REMAINING API ERRORS
    # --------------------------------------------------------------------------

    if [[ -n "${error_message}" ]]; then
        echo
        echo "ERROR: API returned an error for ${lang}."
        echo "Response:"
        cat "${res_file}"
        exit 1
    fi

    echo "Transcription request succeeded."

    # Upload request and response files to Cloud Storage.
    echo "Uploading request and response files..."

    gcloud storage cp \
        "${req_file}" \
        "gs://${BUCKET_NAME}/"

    gcloud storage cp \
        "${res_file}" \
        "gs://${BUCKET_NAME}/"

    echo "SUCCESS: ${lang} transcription files uploaded."
    echo "Request:  ${req_file}"
    echo "Response: ${res_file}"
}

# ==============================================================================
# 6. EXECUTE TASK 2: ENGLISH TRANSCRIPTION
# ==============================================================================

process_audio \
    "${EN_REQ_FILE}" \
    "${EN_RES_FILE}" \
    "${EN_AUDIO_URI}" \
    "${EN_LANG}" \
    "${EN_CHANNELS}"

# ==============================================================================
# 7. EXECUTE TASK 3: SPANISH TRANSCRIPTION
# ==============================================================================

process_audio \
    "${SP_REQ_FILE}" \
    "${SP_RES_FILE}" \
    "${SP_AUDIO_URI}" \
    "${SP_LANG}" \
    "${SP_CHANNELS}"

# ==============================================================================
# 8. COMPLETION SUMMARY
# ==============================================================================

echo
echo "==========================================================="
echo "LAB AUTOMATION COMPLETE!"
echo "==========================================================="

echo "Verifying files in gs://${BUCKET_NAME}/..."

gcloud storage ls "gs://${BUCKET_NAME}/"

echo
echo "Both transcription tasks completed successfully."
echo "Return to the lab and click Check my progress."
echo "==========================================================="
```

## Step 4: Fix the audio channel count error

### Error message

The Spanish transcription may return an error similar to this:

```text
ERROR: API returned an error for es-ES.
{
  "error": {
    "code": 400,
    "message": "audio_channel_count `2` in RecognitionConfig must either be unspecified or match the value in the FLAC header `1`.",
    "status": "INVALID_ARGUMENT"
  }
}
```

### Automatic fix

The supplied script detects this particular channel-count mismatch and retries that transcription request with:

```json
"audioChannelCount": 1
```

It keeps the retry specific to the language that failed. The English and Spanish audio files may have different channel counts.

If the API returns a different error, the script prints the API response and stops rather than silently treating the request as successful.

### Manual fix

If you prefer to change the channel counts manually, open the script:

```bash
nano run_lab.sh
```

Find:

```bash
EN_CHANNELS=2
SP_CHANNELS=2
```

Change the variables to match the actual files. For example, if both audio files are mono:

```bash
EN_CHANNELS=1
SP_CHANNELS=1
```

The reported FLAC error confirms that the Spanish file has one channel. It does not establish the channel count of the English WAV file, so check that file separately before changing `EN_CHANNELS`.

Save the file with `Ctrl+O`, press `Enter`, and exit with `Ctrl+X`.

Run the script again:

```bash
./run_lab.sh
```

## Troubleshooting

### Invalid API key

Check that `USER_API_KEY` contains the actual API key instead of the placeholder.

### Incorrect active project

Run:

```bash
gcloud config get-value project
```

Confirm that the active project is the one provided by your current lab.

### Bucket already exists

This is expected if the bucket was created previously. The script skips bucket creation if the existing bucket is accessible.

### Audio channel count mismatch

Check the API's error message. For the specific mismatch involving a FLAC header that reports one channel, retry with `audioChannelCount = 1`.

### API or permission error

Inspect the error printed in Cloud Shell. Check API enablement, credentials, project selection, and access permissions.

### Script stops after the first transcription

The script uses `set -euo pipefail`. It stops when an unhandled command fails or when the API returns an error that the script cannot resolve. Review the response printed in Cloud Shell before rerunning it.
