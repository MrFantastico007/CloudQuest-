# GCP Challenge Lab: Analyze Images with the Cloud Vision API (ARC122)

## Overview

This guide covers the manual setup for Task 1 and automates the remaining image analysis tasks using the Google Cloud Vision API.

The automation script dynamically discovers the Cloud Storage bucket, finds an image, performs text and landmark detection, and uploads the API response files to the bucket.

## Step 1: Manually Set Up the Cloud Vision API

Complete the required initial setup manually in Google Cloud Console.

1. Open Google Cloud Console in your active Cloud Skills Boost lab project.
2. Navigate to **APIs & Services → Library**.
3. Search for **Cloud Vision API**.
4. Open the API page and click **Enable** if it is not already enabled.
5. Navigate to **APIs & Services → Credentials**.
6. Click **Create credentials → API key**, if permitted by the lab environment.
7. Copy the generated API key for use in the automation script.

If the lab's Task 1 instructions specify a different setup, follow the lab instructions exactly.

## Step 2: Create the Automation Script

Open Google Cloud Shell and create the script:

```bash
nano run_lab.sh
```

Paste the following complete Bash script into the editor.

```bash
#!/usr/bin/env bash
set -euo pipefail

echo "=========================================================="
echo " Automating: Analyze Images with the Cloud Vision API"
echo "=========================================================="

# ==========================================================
# 1. USER-EDITABLE VARIABLES
# ==========================================================
# Paste the API key created manually in Task 1.
API_KEY="YOUR_API_KEY_HERE"

# ==========================================================
# 2. DYNAMIC CONFIGURATION & SETUP
# ==========================================================
PROJECT_ID=$(gcloud config get-value project 2>/dev/null)

if [[ -z "${PROJECT_ID}" || "${PROJECT_ID}" == "(unset)" ]]; then
    echo "[!] ERROR: No active Google Cloud project is configured."
    exit 1
fi

echo "[*] Project ID: ${PROJECT_ID}"

if [[ -z "${API_KEY}" || "${API_KEY}" == "YOUR_API_KEY_HERE" ]]; then
    echo "[!] ERROR: Replace YOUR_API_KEY_HERE with your actual API key."
    exit 1
fi

# Discover the pre-provisioned lab bucket.
echo "[*] Discovering Cloud Storage bucket..."

BUCKET_URL=$(
    gcloud storage ls 2>/dev/null |
    grep -E 'gs://qwiklabs-gcp-.*-bucket/?$' |
    head -n 1 |
    sed 's:/*$::' || true
)

if [[ -z "${BUCKET_URL}" ]]; then
    echo "[!] ERROR: Could not find the expected Qwiklabs bucket."
    echo "Check the bucket name in Cloud Storage and update the discovery pattern if needed."
    exit 1
fi

echo "[+] Found Bucket: ${BUCKET_URL}"

# Discover an image inside the bucket.
echo "[*] Discovering image file in the bucket..."

IMAGE_URI=$(
    gcloud storage ls --recursive "${BUCKET_URL}/" 2>/dev/null |
    grep -iE '\.(jpg|jpeg|png)$' |
    head -n 1 || true
)

if [[ -z "${IMAGE_URI}" ]]; then
    echo "[!] ERROR: Could not find a JPG, JPEG, or PNG image in the bucket."
    exit 1
fi

echo "[+] Found Image: ${IMAGE_URI}"

# ==========================================================
# 3. TASK EXECUTION: TEXT DETECTION
# ==========================================================
echo "[*] Task: Running TEXT_DETECTION..."

cat > request.json <<EOF
{
  "requests": [
    {
      "image": {
        "source": {
          "gcsImageUri": "${IMAGE_URI}"
        }
      },
      "features": [
        {
          "type": "TEXT_DETECTION",
          "maxResults": 10
        }
      ]
    }
  ]
}
EOF

curl --fail-with-body -sS -X POST \
    -H "Content-Type: application/json" \
    --data-binary @request.json \
    "https://vision.googleapis.com/v1/images:annotate?key=${API_KEY}" \
    -o text-response.json

if grep -q '"error"' text-response.json; then
    echo "[!] ERROR: Cloud Vision API returned an error for text detection."
    cat text-response.json
    exit 1
fi

echo "[*] Uploading text-response.json to bucket..."
gcloud storage cp text-response.json "${BUCKET_URL}/text-response.json"

# ==========================================================
# 4. TASK EXECUTION: LANDMARK DETECTION
# ==========================================================
echo "[*] Task: Running LANDMARK_DETECTION..."

cat > request.json <<EOF
{
  "requests": [
    {
      "image": {
        "source": {
          "gcsImageUri": "${IMAGE_URI}"
        }
      },
      "features": [
        {
          "type": "LANDMARK_DETECTION",
          "maxResults": 10
        }
      ]
    }
  ]
}
EOF

curl --fail-with-body -sS -X POST \
    -H "Content-Type: application/json" \
    --data-binary @request.json \
    "https://vision.googleapis.com/v1/images:annotate?key=${API_KEY}" \
    -o landmark-response.json

if grep -q '"error"' landmark-response.json; then
    echo "[!] ERROR: Cloud Vision API returned an error for landmark detection."
    cat landmark-response.json
    exit 1
fi

echo "[*] Uploading landmark-response.json to bucket..."
gcloud storage cp landmark-response.json "${BUCKET_URL}/landmark-response.json"

echo "=========================================================="
echo "[+] Automation script finished."
echo "Verify the response files and click 'Check my progress' in the lab."
echo "=========================================================="
```

## Step 3: Configure the API Key

Inside the script, locate:

```bash
API_KEY="YOUR_API_KEY_HERE"
```

Replace `YOUR_API_KEY_HERE` with the API key you created manually in Step 1.

For example:

```bash
API_KEY="PASTE_YOUR_ACTUAL_KEY_HERE"
```

Do not share your API key or commit it to a public repository.

## Step 4: Save and Validate the Script

Save the file in Nano:

1. Press `Ctrl + O`.
2. Press `Enter`.
3. Press `Ctrl + X`.

Check the Bash syntax:

```bash
bash -n run_lab.sh
```

If the command produces no output, the script passes the Bash syntax check.

## Step 5: Run the Automation Script

Make the script executable:

```bash
chmod +x run_lab.sh
```

Execute it:

```bash
./run_lab.sh
```

The script will attempt to:

1. Detect the active Google Cloud project.
2. Discover the pre-provisioned Cloud Storage bucket.
3. Locate an image in the bucket.
4. Run `TEXT_DETECTION` through the Cloud Vision API.
5. Upload `text-response.json` to the bucket.
6. Run `LANDMARK_DETECTION` through the Cloud Vision API.
7. Upload `landmark-response.json` to the bucket.

## Step 6: Verify the Output Files

List the files in the discovered bucket:

```bash
gcloud storage ls gs://YOUR_BUCKET_NAME/
```

Replace `YOUR_BUCKET_NAME` with the actual bucket name printed by the script.

The expected response files are:

- `text-response.json`
- `landmark-response.json`

You can inspect the local response files with:

```bash
cat text-response.json
cat landmark-response.json
```

Verify that the files contain API responses rather than error messages.

## Step 7: Check Lab Progress

Return to the Google Cloud Skills Boost lab page.

1. Confirm that the manual setup for Task 1 is complete.
2. Click **Check my progress** for the text detection task.
3. Click **Check my progress** for the landmark detection task.
4. Confirm that each task is marked complete.

## Important Notes

- Task 1 is completed manually. This script does not create an API key or enable APIs.
- The Cloud Vision API must already be enabled, and the API key must be valid.
- The script assumes the bucket name matches `qwiklabs-gcp-*-bucket` and contains a JPG, JPEG, or PNG image.
- The script does not change bucket permissions or make the image public. If the API cannot access the image, follow the lab's instructions for granting the required access.
- A successful API response does not guarantee that the lab grader will accept the results. Use the exact resource names and output filenames required by your lab instructions.
- Always verify task completion using the lab's **Check my progress** controls.
