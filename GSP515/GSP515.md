# GSP-515: Explore Generative AI with the Gemini API

## Task 1: Send a Prompt to Gemini

### Step 1: Enable the API in Cloud Console

**Important:** The lab grading system explicitly checks whether you enabled the API through the Google Cloud Console UI.

1. Open the [Google Cloud Console](https://console.cloud.google.com/).
2. Click the **Navigation Menu** (☰) in the top-left corner.
3. Navigate to **Agent Platform** or search for it using the top search bar.
4. If prompted, click **Enable API** or **Enable All Recommended APIs**.
5. Wait a few seconds for the API to activate.

### Step 2: Set Variables in Cloud Shell

Open a fresh Google Cloud Shell terminal and copy-paste the following commands. Replace the project ID and model ID if your lab instructions specify different values.

```bash
PROJECT_ID="your_proj_id"
LOCATION="global"
API_ENDPOINT="aiplatform.googleapis.com"
MODEL_ID="gemini-3.5-flash"
```

### Step 3: Send a Request Using curl

Copy and paste the entire command below into Cloud Shell:

```bash
curl -X POST \
  -H "Authorization: Bearer $(gcloud auth print-access-token)" \
  -H "Content-Type: application/json" \
  "https://${API_ENDPOINT}/v1/projects/${PROJECT_ID}/locations/${LOCATION}/publishers/google/models/${MODEL_ID}:generateContent" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "Why is the sky blue?"
          }
        ]
      }
    ]
  }'
```

### Step 4: Verify Task 1

1. Wait for the terminal to return a JSON response containing Gemini's generated text.
2. Wait approximately 60 seconds.
3. Return to the lab instructions page.
4. Click **Check my progress** for Task 1.

### Alternative Method if the curl Request Fails

If the API request fails because of a model ID, endpoint, access, or availability issue, try the Gemini web interface:

1. Open the [Gemini API documentation](https://cloud.google.com/vertex-ai/docs/generative-ai/multimodal/send-chat-prompts-gemini#send_chat_prompts) in an **Incognito window**.
2. Navigate to **Model Garden** in Google Cloud Console.
3. Search for **Gemini 3.5 Flash**, as specified in your lab instructions.
4. Open the model and navigate to its Studio interface.
5. Enter the following prompt:

   ```text
   Why is the sky blue?
   ```

6. Submit the prompt and wait for Gemini to generate a response.
7. Return to the lab interface and click **Check my progress** for Task 1.

**Note:** The alternative method depends on the model being available in your project and the lab accepting that interaction. If the model name or endpoint is invalid, use the exact model and endpoint specified by your active lab.

## Troubleshooting

- **Authentication error:** Confirm that Cloud Shell or the notebook is using the correct lab credentials.
- **Invalid model or endpoint:** Verify the model ID, API endpoint, and location against the active lab instructions.
- **API not enabled:** Enable the required API through the Google Cloud Console UI if the grader explicitly requires it.
- **Permission denied:** Check the permissions granted to your lab account or service account.
- **Notebook missing:** Upload the provided notebook again and confirm the filename ends in `.ipynb`.
- **Notebook cell failure:** Execute cells in order and resolve dependency or configuration errors before proceeding.
