# GCP Challenge Lab: Implement Speech and Language Solutions (ARC132)

## Step 1: Export Your API Key in Cloud Shell

Since Task 1 was created manually, retrieve your API key string from the Console (**APIs & Services → Credentials**), copy it, and run this in Cloud Shell:

```bash
export API_KEY="YOUR_COPIED_API_KEY"
```

## Step 2: Run the Automated Script for Tasks 2–5

Create the script and paste the following content into it.

```bash
#!/usr/bin/env bash
#
# GCP Challenge Lab: Implement Speech and Language Solutions (ARC132)
# Tasks 2 to 5 Execution Script
#

set -euo pipefail

# ==============================================================================
# USER-EDITABLE CONFIGURATION VARIABLES
# ==============================================================================
export ZONE="us-central1-a"
export VM_NAME="lab-vm"

# Check if API_KEY is present
if [ -z "${API_KEY:-}" ]; then
  echo "ERROR: API_KEY environment variable is not set. Please run 'export API_KEY=\"your_key\"' first."
  exit 1
fi

# Helper function to execute commands on the remote VM via SSH
run_on_vm() {
  gcloud compute ssh "${VM_NAME}" --zone="${ZONE}" --command="$1" --quiet
}

# ==============================================================================
# TASK 2: SYNTHESIZE SPEECH FROM TEXT USING TEXT-TO-SPEECH API
# ==============================================================================
echo -e "\n==> Task 2: Synthesizing speech using Text-to-Speech API..."

run_on_vm "
cat << 'EOF' > synthesize-text.json
{
  \"input\": {
    \"text\": \"Cloud Text-to-Speech API allows developers to include natural-sounding, synthetic human speech as playable audio in their applications. The Text-to-Speech API converts text or Speech Synthesis Markup Language (SSML) input into audio data like MP3 or LINEAR16 (the encoding used in WAV files).\"
  },
  \"voice\": {
    \"languageCode\": \"en-gb\",
    \"name\": \"en-GB-Standard-A\",
    \"ssmlGender\": \"FEMALE\"
  },
  \"audioConfig\": {
    \"audioEncoding\": \"MP3\"
  }
}
EOF

curl -s -X POST \
  -H \"Content-Type: application/json\" \
  \"https://texttospeech.googleapis.com/v1/text:synthesize?key=${API_KEY}\" \
  -d @synthesize-text.json > synthesize-text.txt

cat << 'EOF' > tts_decode.py
import argparse
from base64 import decodebytes
import json

def decode_tts_output(input_file, output_file):
    with open(input_file) as input_data:
        response = json.load(input_data)
        audio_data = response['audioContent']
        with open(output_file, 'wb') as new_file:
            new_file.write(decodebytes(audio_data.encode('utf-8')))

if __name__ == '__main__':
    parser = argparse.ArgumentParser(description='Decode output from Cloud Text-to-Speech')
    parser.add_argument('--input', help='The response from the Text-to-Speech API.', required=True)
    parser.add_argument('--output', help='The name of the audio file to create', required=True)
    args = parser.parse_args()
    decode_tts_output(args.input, args.output)
EOF

python3 tts_decode.py --input \"synthesize-text.txt\" --output \"synthesize-text-audio.mp3\"
"

# ==============================================================================
# TASK 3: TRANSCRIBE SPEECH TO TEXT WITH CLOUD SPEECH API
# ==============================================================================
echo -e "\n==> Task 3: Transcribing audio with Cloud Speech API..."

run_on_vm "
cat << 'EOF' > speech_request_fr.json
{
  \"config\": {
    \"encoding\": \"FLAC\",
    \"languageCode\": \"fr-FR\"
  },
  \"audio\": {
    \"uri\": \"gs://cloud-samples-data/speech/corbeau_renard.flac\"
  }
}
EOF

curl -s -X POST \
  -H \"Content-Type: application/json\" \
  \"https://speech.googleapis.com/v1/speech:recognize?key=${API_KEY}\" \
  -d @speech_request_fr.json > speech_response.json
"

# ==============================================================================
# TASK 4: TRANSLATE TEXT WITH CLOUD TRANSLATION API
# ==============================================================================
echo -e "\n==> Task 4: Translating text using Cloud Translation API..."

run_on_vm "
curl -s -X POST \
  -H \"Content-Type: application/json\" \
  \"https://translation.googleapis.com/language/translate/v2?key=${API_KEY}\" \
  -d '{
    \"q\": \"これは日本語です。\",
    \"target\": \"en\"
  }' > translation_response.txt
"

# ==============================================================================
# TASK 5: DETECT LANGUAGE WITH CLOUD TRANSLATION API
# ==============================================================================
echo -e "\n==> Task 5: Detecting language with Cloud Translation API..."

run_on_vm "
curl -s -X POST \
  -H \"Content-Type: application/json\" \
  \"https://translation.googleapis.com/language/translate/v2/detect?key=${API_KEY}\" \
  -d '{
    \"q\": \"Este%é%japonês.\"
  }' > detection_response.txt
"

echo -e "\n=============================================================================="
echo " Tasks 2 through 5 completed successfully!"
echo "=============================================================================="
```

## Variables to Edit

- **`ZONE`**: Ensure it matches your `lab-vm` zone (default: `"us-central1-a"`).
- **`VM_NAME`**: Set to `"lab-vm"`.

## Execution Instructions

1. In **Google Cloud Shell**, open/create the file:

   ```bash
   nano run_tasks.sh
   ```

2. Paste the script above and save (`Ctrl+O`, `Enter`, `Ctrl+X`).

3. Make it executable and run:

   ```bash
   chmod +x run_tasks.sh
   ./run_tasks.sh
   ```

4. Click **Check my progress** on Tasks 2, 3, 4, and 5 in the lab interface.
