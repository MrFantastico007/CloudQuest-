# GCP Challenge Lab: Implement Speech and Language Solutions (ARC132)

## Automated Script for Tasks 2–5

This script automatically detects the active Google Cloud project and the zone of `lab-vm`. It supports customizable filenames for Tasks 2–5 and executes the Text-to-Speech, Speech-to-Text, and Cloud Translation API requests.

```bash
#!/usr/bin/env bash
#
# GCP Challenge Lab: Implement Speech and Language Solutions (ARC132)
# Fully Parameterized Script (Handles any randomized filename variant)
#

set -euo pipefail

# ==============================================================================
# USER-EDITABLE CONFIGURATION VARIABLES
# Look at your lab instructions and replace these values with your exact names!
# ==============================================================================

export API_KEY="[Enter your API key]"

# Task 2 Variables
export TASK2_REQ_JSON="synthesize-text.json"
export TASK2_RES_TXT="synthesize-text.txt"
export TASK2_RES_AUDIO="synthesize-text-audio.mp3"

# Task 3 Variables
export TASK3_REQ_JSON="request.json"
export TASK3_RES_JSON="speech_response_fr.json"

# Task 4 Variables
export TASK4_RES_TXT="translated_response.txt"

# Task 5 Variables
export TASK5_RES_TXT="detected_response.txt"

# ==============================================================================
# DYNAMIC ENVIRONMENT & ZONE DETECTION
# ==============================================================================
echo "==> Auto-detecting active project and VM zone..."

PROJECT_ID=$(gcloud config get-value project 2>/dev/null)
VM_NAME="lab-vm"
ZONE=$(gcloud compute instances list --filter="name=${VM_NAME}" --format="value(zone)" 2>/dev/null || true)

if [ -z "$ZONE" ]; then
  echo "ERROR: Could not locate '${VM_NAME}'. Ensure the instance is running."
  exit 1
fi

echo "Project ID: ${PROJECT_ID}"
echo "VM Found: ${VM_NAME} in Zone: ${ZONE}"

run_on_vm() {
  gcloud compute ssh "${VM_NAME}" --zone="${ZONE}" --command="$1" --quiet
}

# ==============================================================================
# TASK 2: SYNTHESIZE SPEECH FROM TEXT USING TEXT-TO-SPEECH API
# ==============================================================================
echo -e "\n==> Task 2: Synthesizing speech using Text-to-Speech API..."

run_on_vm "
cat << 'EOF' > ${TASK2_REQ_JSON}
{
  \"input\": {
    \"text\": \"Cloud Text-to-Speech API allows developers to include natural-sounding, synthetic human speech as playable audio in their applications. The Text-to-Speech API converts text or Speech Synthesis Markup Language (SSML) input into audio data like MP3 or LINEAR16 (the encoding used in WAV files).\"
  },
  \"voice\": {
    \"languageCode\": \"en-gb\",
    \"name\": \"en-GB-Standard-A\",
    \"ssmlGender\": \"FEMALE\"
  },
  \"audioConfig\": {
    \"audioEncoding\": \"MP3\"
  }
}
EOF

curl -s -X POST \
  -H \"Content-Type: application/json\" \
  \"https://texttospeech.googleapis.com/v1/text:synthesize?key=${API_KEY}\" \
  -d @${TASK2_REQ_JSON} > ${TASK2_RES_TXT}

cat << 'EOF' > tts_decode.py
import argparse
from base64 import decodebytes
import json

def decode_tts_output(input_file, output_file):
    with open(input_file) as input_data:
        response = json.load(input_data)
        audio_data = response['audioContent']
        with open(output_file, 'wb') as new_file:
            new_file.write(decodebytes(audio_data.encode('utf-8')))

if __name__ == '__main__':
    parser = argparse.ArgumentParser(description='Decode output from Cloud Text-to-Speech')
    parser.add_argument('--input', help='The response from the Text-to-Speech API.', required=True)
    parser.add_argument('--output', help='The name of the audio file to create', required=True)
    args = parser.parse_args()
    decode_tts_output(args.input, args.output)
EOF

python3 tts_decode.py --input \"${TASK2_RES_TXT}\" --output \"${TASK2_RES_AUDIO}\"
"

# ==============================================================================
# TASK 3: TRANSCRIBE SPEECH TO TEXT WITH CLOUD SPEECH API
# ==============================================================================
echo -e "\n==> Task 3: Transcribing audio with Cloud Speech API..."

run_on_vm "
cat << 'EOF' > ${TASK3_REQ_JSON}
{
  \"config\": {
    \"encoding\": \"FLAC\",
    \"languageCode\": \"fr-FR\"
  },
  \"audio\": {
    \"uri\": \"gs://cloud-samples-data/speech/corbeau_renard.flac\"
  }
}
EOF

curl -s -X POST \
  -H \"Content-Type: application/json\" \
  \"https://speech.googleapis.com/v1/speech:recognize?key=${API_KEY}\" \
  -d @${TASK3_REQ_JSON} > ${TASK3_RES_JSON}
"

# ==============================================================================
# TASK 4: TRANSLATE TEXT WITH CLOUD TRANSLATION API
# ==============================================================================
echo -e "\n==> Task 4: Translating text using Cloud Translation API..."

run_on_vm "
curl -s -X POST \
  -H \"Content-Type: application/json\" \
  \"https://translation.googleapis.com/language/translate/v2?key=${API_KEY}\" \
  -d '{
    \"q\": \"これは日本語です。\",
    \"target\": \"en\"
  }' > ${TASK4_RES_TXT}
"

# ==============================================================================
# TASK 5: DETECT LANGUAGE WITH CLOUD TRANSLATION API
# ==============================================================================
echo -e "\n==> Task 5: Detecting language using Cloud Translation API..."

run_on_vm "
curl -s -X POST \
  -H \"Content-Type: application/json\" \
  \"https://translation.googleapis.com/language/translate/v2/detect?key=${API_KEY}\" \
  -d '{
    \"q\": \"Este%é%japonês.\"
  }' > ${TASK5_RES_TXT}
"

echo -e "\n=============================================================================="
echo " Tasks 2 through 5 executed with your custom filenames!"
echo "=============================================================================="
```

## Variables

Update these values in the script to match your lab instructions:

- **`API_KEY`**: Replace `[Enter your API key]` with your Google Cloud API key.
- **`VM_NAME`**: The Compute Engine VM name, set to `lab-vm` by default.
- **`TASK2_REQ_JSON`**: Task 2 request JSON filename.
- **`TASK2_RES_TXT`**: Task 2 API response filename.
- **`TASK2_RES_AUDIO`**: Task 2 generated audio filename.
- **`TASK3_REQ_JSON`**: Task 3 request JSON filename.
- **`TASK3_RES_JSON`**: Task 3 API response filename.
- **`TASK4_RES_TXT`**: Task 4 response filename.
- **`TASK5_RES_TXT`**: Task 5 response filename.
- **`ZONE`**: Detected automatically from the VM configuration.

## Execution Instructions

### 1. Open `run_tasks.sh`

In Google Cloud Shell, run:

```bash
nano run_tasks.sh
```

### 2. Paste and save the script

Clear the existing text, paste the complete Bash script above, and save:

- Press `Ctrl + O`.
- Press `Enter`.
- Press `Ctrl + X`.

Make sure you paste only the Bash script into `run_tasks.sh`, not the README headings or Markdown code fences.

### 3. Make it executable and run

```bash
chmod +x run_tasks.sh
bash -n run_tasks.sh
./run_tasks.sh
```

If `bash -n run_tasks.sh` produces no output, the script has passed the Bash syntax check.

### 4. Verify task completion

Return to the Google Cloud Skills Boost lab interface and click **Check my progress** for Tasks 2, 3, 4, and 5.
